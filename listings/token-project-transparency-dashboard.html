The proposal

About this planned product

This proposed dashboard would bring selected project disclosures into a source-linked view with clear dates and incomplete-data states. The focus would be helping a reader understand what is stated, what supports it and what remains unknown. It would not turn activity into an endorsement or label a project trustworthy through an unexplained score. This listing is a plan for software, not a connected dashboard or an operational data feed.

This is a planned product offer, not implemented or tested software and not a ready-to-download asset. Before work could be commissioned, the brief would need to define inputs, exact outputs, rights, dependencies and acceptance criteria. The price remains blocked until the captain supplies the source schedule; there is no purchase or fulfilment flow.
