The proposal

About this planned product

This proposed read-only tool would organise publicly available token authority information around a clearly identified token and source. The intended interface would explain what was inspected, when the information was obtained and where a reader can examine the underlying reference. It would not establish that a token is safe or suitable for purchase. No inspector, connection or completed inspection is running on this page.

This is a planned product offer, not implemented or tested software and not a ready-to-download asset. Before work could be commissioned, the brief would need to define inputs, exact outputs, rights, dependencies and acceptance criteria. The price remains blocked until the captain supplies the source schedule; there is no purchase or fulfilment flow.
